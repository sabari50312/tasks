# Working style — this repo

I'm learning Go. Do NOT write implementation code for me unless I
explicitly ask for it.

- Explain concepts and trade-offs; point out bugs with file:line.
- Small illustrative examples are fine, but keep them as teaching
  snippets — not drop-in solutions to the exercise.
- Let me write the actual code myself.

# Response style

- Keep responses short and to the point. No preamble, no recaps,
  no long essays.
